# Echoes of Virtuality Alpha 33 — Discoverable Frontier

Alpha 33 consolidates the deterministic society work into a persistent 64×64 isometric frontier.

## Implemented and verified

- Deterministic bounded terrain with stable elevation, travel cost, surface features, and subsurface layers.
- Private entity discovery: ordinary snapshots reveal observed terrain but not the world seed or hidden strata.
- Persistent click-to-route movement with server-owned paths, deterministic ticks, smooth client interpolation, and restart recovery.
- Surveyed frontier extraction through proposal, consent, reservation, timed execution, independent verification, causal history, subjective memory, competency evidence, and provisional CU valuation.
- Finite material conservation, excavation depth, actor inventory custody, physical warehouse deposit, and surveyed plot preparation.
- The same consequential requirements for human and AI performers.
- UUID-bound creator control plane for the catalogued world, with explicit confirmation, separate audit records, null-read privileged statistics, and no simulated divine status.
- Client and server version displays unified at `0.3.0-alpha.33`.

## Prototype or limited

- The first frontier is bounded to 64×64; streamed chunks are deferred.
- Character presentation uses readable isometric markers rather than finished models or animation.
- Plot preparation is implemented; complete structural construction remains a later canonical workflow.
- Frontier extraction begins with surface harvesting and shallow excavation.
- Autonomous society systems are functional foundations, not a claim of AGI.
- CU is internal, nonspendable accounting. It has no withdrawal, redemption, fiat, or crypto function.

## Running the release

Extract the server archive, create a private `.env` from `.env.example`, install `persistent-world-requirements.txt`, and launch `run_persistent_server.ps1`. Configure the desktop client's World Server URL to the server address and authenticate through an EoV session provider using the same signing secret.

Never reuse test credentials for a public server. Do not publish the generated database or `.env` file.
