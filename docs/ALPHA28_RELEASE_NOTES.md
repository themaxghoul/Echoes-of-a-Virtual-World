# Echoes of Virtuality Alpha.28

## Relationships now change cooperation

Trust is no longer merely a profile statistic.

- Dev's trust derives from recorded checkout, overdue, return, and custody history.
- Ordinary settlement-resource checkout is refused below a defined trust threshold.
- Refusal is a persistent NPC decision with an identified decision maker, cause, trust value, and recovery option.
- Repeated requests within six ticks reuse the existing refusal instead of manufacturing history spam.
- Unresolved restitution takes priority over new custody requests.
- Low-trust actors can request exactly one unit under a shorter supervised agreement.
- Returning supervised property increases trust and records a causal recovery event.
- Reaching the ordinary threshold resolves prior refusal records and restores standard access.
- Actors at zero trust retain a repeated supervised-work path to recovery.
- Dev explains current trust and available cooperation through proximity dialogue.
- Trust history, refusals, supervised agreements, recovery, access, and dialogue survive restart.

The persistent schema advances to 20 and migrates existing worlds in place.
