# Echoes of Virtuality Alpha.31

## Persistent causality is now visible in the isometric client

The schema-22 stewardship and teaching systems now have an accessible, server-authoritative presentation.

- The client renders only data contained in the authenticated persistent-world snapshot.
- Environmental cards identify the depletion cause, order, site, worker, inspector, current tiles, and status.
- Unresolved blockers display exact missing inputs.
- Traveling, recovery, return, and completion states explain the next expected consequence.
- Verified restoration displays the measured surviving stock.
- Teaching cards identify instructor, learner, domain, status, and source stewardship evidence.
- Completed demonstrations show before-and-after competency.
- A capability roster shows the competencies that can affect future work assignment.
- Older sparse worlds render no fabricated stewardship or teaching records.
- The panel has an accessible region name and text-based state; it does not depend upon color alone.

This release retains persistent schema 22. It changes observability rather than durable simulation semantics.
