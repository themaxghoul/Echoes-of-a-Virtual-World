# Workbench construction implementation plan

Goal: implement the user-approved procedural/AI-assisted crafting approach.
Design: [CRAFTING_DESIGN.md](../../CRAFTING_DESIGN.md).
Execution: inline, preserving existing world and deployment identifiers.

1. Shared schematic rules and backend: write failing tests for workbench validity,
   material conservation, idempotency, ownership, footprint collision and restart.
   Add pure schema/template helpers; add craft commands to the kernel transaction.
2. AI draft provider: persist fallback before inference; validate bounded model
   parameters; test failure, budget exhaustion, replay and concurrent requests.
3. Workshop UI: toolbar entry, plank processing, description generator, editable
   layer grid, live cost/validity preview, saved designs and explicit construction.
4. Graphics: shared seeded appearance helpers and block mesh rendering in both
   projections; preserve terrain coordinates and existing movement behavior.
5. Verify: full Node and Python suites, browser crafting/reload and both views,
   malformed schematics and rollback tests; document known alpha limits.
6. Publish: review diff, push through GitHub, deploy existing free Worker, check
   Pages workflow and public assets without mutating production QA inventory.
